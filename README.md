# Novena a Santa Teresita del Niño Jesús

Página sencilla para rezar la novena a Santa Teresita del Niño Jesús desde el celular.

## Contenido

- `index.html`: la novena. Tracker de 9 días, contador de Glorias, oraciones de cada día, botón para marcar el día como rezado, controles de tamaño de letra y botón para compartir la novena (hoja nativa del celular o WhatsApp).
- `historia.html`: la historia de Santa Teresita, con un episodio de podcast en Spotify y un botón para volver a la novena.
- `teresa.png`: imagen usada en ambas páginas.

## Cómo verla

Abre `index.html` en el navegador. No necesita instalación ni servidor.

Para publicarla en GitHub Pages:

1. Sube estos archivos a un repositorio.
2. En Settings > Pages, elige la rama principal y la carpeta raíz.
3. La página quedará disponible en la dirección que indique GitHub.

## Notas

- El avance se guarda en el navegador de cada persona (localStorage). No se comparte entre dispositivos.
- Las fuentes Cormorant Garamond y Karla se cargan desde Google Fonts.
- La información de la página de historia proviene de la biografía en Wikipedia en español. Conviene revisarla con una fuente católica antes de publicarla.
